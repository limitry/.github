[![Limitry](banner.png)](https://limitry.com)

Limitry is the limits, credits and budgets layer for the software you build: give each of your users, teams, tenants, API keys or agents an allowance, and before any costly request one call tells your code whether it may happen.

## Start

```bash
npm install @limitry/sdk               # TypeScript
pip install limitry                    # Python
npm install -g @limitry/cli            # the command line
npx skills add limitry/limitry-skills  # your AI agent
```

Then follow [the quickstart](https://limitry.com/docs/quickstart/).
